This program procedurally paints a colossal glowing jellyfish surging from an indigo abyss into a starfield, with streaming tentacles, sparks, and a tiny lantern boat for scale. Run it with Python 3 to write the deterministic PNG to your chosen output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
